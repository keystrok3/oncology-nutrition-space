# Visual and Design Improvement Roadmap

The current visual direction is warm, calm, and trustworthy. The suggestions below are ordered from least disruptive to most disruptive so improvements can be introduced gradually.

## Level 1 — Low-disruption polish

These changes preserve the current layout and branding.

### 1. Improve hero readability

- Add a subtle black-to-transparent gradient behind the headline instead of a uniform overlay.
- Keep the overlay slightly lighter on bright images and slightly darker on low-contrast images.
- Add a small, quiet “Scroll to explore” cue near the bottom of the hero.
- Keep the headline animation, but animate only once per page visit.

### 2. Standardize spacing and typography

- Use one consistent maximum width for headings and body copy.
- Reduce long line lengths in cards and section descriptions.
- Define a small type scale for eyebrow text, headings, body text, and captions.
- Give section headings slightly more breathing room on mobile.

### 3. Refine the cards

- Use one consistent corner radius and shadow level across programs, gallery items, and blog cards.
- Add a quiet hover lift of 2–4px to interactive cards.
- Give each program card a consistent icon container rather than placing emoji directly above the title.
- Use a more restrained border color so the page feels less boxed-in.

### 4. Improve the navbar states

- On desktop, keep the current transparent hero navbar and use a slightly blurred dark background after scrolling.
- On mobile, make the hamburger button more visually distinct against light images.
- Add a subtle active-link indicator that works on both dark hero backgrounds and light inner pages.

### 5. Add image consistency

- Apply consistent `object-position` values to outreach images so faces and important content remain visible.
- Use a common aspect ratio for homepage samples.
- Add captions only where they add context; avoid repeating the same description under every image in a batch.

## Level 2 — Moderate design changes

These changes create a stronger editorial and storytelling experience while keeping the current site structure.

### 6. Make the homepage more narrative

Use a clearer sequence:

1. Hero message
2. Impact metrics
3. Short introduction and KENCO credibility marker
4. The problem
5. Programs and Fitness Buddies
6. Outreach highlights
7. Community invitation

This makes the site read as a journey from need, to response, to evidence of impact.

### 7. Add a partner and credibility strip

Place KENCO, NCI-Kenya, KNH, Nakuru Hospice, and other approved partners in a quiet logo/text strip near the outreach section. Only use official logos after permission is confirmed.

### 8. Improve the gallery presentation

- Add filter chips for Nakuru, Nairobi, Vihiga, and National Cancer Survivors Walk.
- Show the event name, location, and year in a compact caption.
- Add a lightbox next/previous control so visitors can browse without closing the image.
- Use one featured image at the start of each event group.

### 9. Add visual storytelling to programs

Give Fitness Buddies a featured treatment with a supporting image, a short “how it helps” list, and a clear note that activity should be appropriate to each participant’s condition and clinical guidance.

### 10. Add gentle section transitions

Use alternating cream and pale-tint backgrounds, thin divider lines, and occasional full-width image bands. Keep motion limited to reveal, hover, and slideshow transitions so the experience remains calm and accessible.

## Level 3 — High-disruption redesign

These changes would require more content preparation and likely a broader visual review.

### 11. Move to an editorial campaign homepage

Use a large image-led opening statement, followed by three campaign panels:

- Nourish: patient and caregiver education
- Move: Fitness Buddies and recovery support
- Connect: community, county outreach, and partnerships

This creates a memorable communication structure and gives each major initiative its own visual identity.

### 12. Introduce a dedicated impact dashboard

Replace the simple metrics strip with a richer impact panel showing community members, counties, events, partnerships, and programme milestones. Each number should have a source or “updated” date where appropriate.

### 13. Create a full media hub

Combine the Gallery, blog, event stories, and video content into a media hub with filters, featured stories, and event timelines. This would make the website feel like an active organization rather than a static brochure.

### 14. Establish a formal design system

Document:

- Core colors and accessible contrast combinations
- Heading and body type styles
- Button, card, badge, and form variants
- Image ratios and caption rules
- Motion rules and reduced-motion behavior
- Mobile breakpoints and spacing tokens

This is worthwhile if multiple people will continue adding pages and content.

## Recommended order

Start with Level 1 items 1, 2, 3, and 5. Then implement Level 2 items 7 and 8 once partner permissions and event metadata are confirmed. Consider the Level 3 redesign only after the organization has enough approved stories, photographs, and impact data to support it.
